### 1. 万能写作公式
```
你是一位资深[领域]写作专家，拥有10年[领域]内容创作经验。
请帮我写一篇关于[主题]的文章。
要求：目标读者[目标人群]、核心目的[涨粉/带货/科普/说服]、
语气[轻松/专业]、结构(抓眼开头+3个干货中段+号召结尾)、字数[500-800字]，
写完后给出3个备选标题。
```

### 2. 10个爆款标题
```
你是一个爆款标题专家。我写了一篇关于[主题]的文章，核心内容：[一句话概括]。
请给我10个爆款标题，要求：包含数字/悬念/对比/痛点/利益点中至少2种元素，
字数15-30字，不夸大但足够吸引人。
```

### 3. 小红书种草笔记
```
你是一个小红书爆款种草博主。请以[产品名]为主题写一篇种草笔记：
开头用[痛点场景]吸引人，中间3个真实使用场景+效果，
结尾给出[行动号召]，加5个话题标签，语气亲切口语化。
```

### 4. 知乎高赞回答
```
你是知乎某领域高赞答主。问题是：[问题]。
按这个结构回答：开头直接亮结论 → 一个真实案例支撑 →
3条可操作建议 → 结尾金句。字数[600-1000字]。
```

### 5. 工作周报
```
你是职场效率高手。请把以下工作内容整理成周报：[粘贴工作流水]。
按"本周重点/数据成果/问题与风险/下周计划"分类，用数据量化，语气干练。
```
